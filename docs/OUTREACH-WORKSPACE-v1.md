# Saved outreach workspace

Live Exa results, recorded Exa research and manual seeds now enter the same browser-local draft workspace. Their source provenance stays separate. Re-loading a source page does not duplicate identical evidence or overwrite an edited message. Different source pages can belong to the same brand, so the count is source-page prospects, not unique companies.

Edit the DM draft, five-second sample brief and research notes. Edits autosave and reset the internal stage to Draft, unsent. Stages are personal review notes, not permission to contact anyone. Save draft version creates a snapshot. Restore draft version preserves the current draft first. Source evidence remains available alongside the drafts.

Export outreach drafts downloads JSON with all source records and versions. Import outreach JSON merges the export without overwriting an existing draft. Imported current drafts are retained as additional versions when a source page already exists. Imported evidence is labeled unverified and contact/submission flags reset. Imports are processed locally, with a 5 MB limit and up to 500 records. Keep the original file if validation rejects it.

Create five-second campaign draft opens a separate campaign and storyboard, preserving the active campaign. Public research is retained as unapproved context. Audience, exact offer, avatar and voice remain empty until supplied. No video, message or generation request is submitted.

Verified hosted behavior: eight manual prospects, edited draft surviving reload, version restore with prior draft preserved, a 25,701-byte JSON download with eight records and saved versions, and a five-second campaign handoff with spend and submission false. The exported JSON round-trip check retained all eight records and marked imported source claims unverified. Mobile browser width was 390 pixels with no document overflow. Physical iPhone testing remains unperformed.
