CORE SYSTEM
Conversation -> structured brand brief -> audience research -> avatar bible -> campaign concepts -> script and storyboard -> multi-agent prompt grading and revisions -> spend approval -> Higgsfield generation -> output review -> editing -> publication approval/scheduling -> performance feedback.

PROMPT REVIEW
Separate specialists grade audience fit, conversion/script, identity/wardrobe/environment continuity, shot timing and feasibility, camera/style, voice/audio, and contradictions/reference bindings. Each must supply evidence and actionable fixes. Final judge considers all findings. Blocking issues stop generation. Revision rounds are bounded. A review belongs to the exact prompt and reference version, and becomes stale when inputs change. Approval is not a guarantee of generated quality.
