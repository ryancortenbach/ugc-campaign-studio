NYC SPONSOR INTEGRATION MAP
Verified 2026-10-24 from https://terac.com/events/hackathon/nyc and https://luma.com/naxtga5l

Terac (host): recruit human audience reviewers for concept/script comparison, then compare original and revised versions. Escalate high-impact disagreements from the prompt graders to a human. Record task ID, cost, completion, judgment, and whether it changed the output.
Whop (sponsor/venue): $97 course checkout, course access entitlement, recurring brand-service checkout and purchase webhooks. T-shirt storefront can use Whop checkout only if physical-goods/order fulfillment is supported and configured. Do not claim physical fulfillment integration before verification.
Lovable (sponsor): implement or generate the customer-facing storefront/course/brand onboarding surfaces using Lovable's supported builder. This local scaffold alone does not constitute using Lovable. A real builder session/export remains pending.
Exa (sponsor): source-backed audience/brand research and DTC prospect discovery. Return URLs, evidence, public business emails if present, and personalized unsent outreach drafts. Never invent contacts or infer a private email from a naming convention.

Community partners: 529 Labs and Bond AI. They are communities, not documented runtime APIs. No artificial software integration is assigned.

NYC's published toolkit is Terac, Whop, Lovable and Exa. Stripe, Render, Linq, Superserve, Replay, Pioneer, Band, Dodo Payments, sandbox0 and Solari appear on the older SF event listing, not on NYC's current sponsor list. Do not add them as requirements without updated evidence.

IMPLEMENTATION CHECK OCTOBER 24, 2026
Exa request shape was checked against https://exa.ai/docs/reference/search . Current adapter retains provider request ID and returned cost metadata. Every email candidate carries the precise source URL, a surrounding published-text excerpt, and a domain comparison. Domain matching does not establish partnership suitability or official ownership. Draft personalization quotes up to twelve words from returned evidence and remains unsent. No live Exa request has been made in this batch. Unit fixtures test source attribution, excluded inboxes, unsafe URLs and missing configuration.

Model prompt review now supports explicit exact-dialogue locks. The lock is part of the input fingerprint. If a proposed revision changes a locked utterance or breaks readiness, that revision is retained as rejected and the last valid prompt remains current. No next review round is launched for that rejected candidate. A malformed severity from a grader also blocks the gate. These are tested software behaviors, not evidence that any actual creative prompt has passed independent model review.
