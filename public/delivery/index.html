THE OPERATING SYSTEM

Follow one campaign through the workspace.

  1. Guided chat intake: capture the eight brief fields, edit them, save a campaign and define the identity.
  2. Production packet: edit a five-, fifteen- or thirty-second storyboard, set character-world locks, save versions and restore a draft.
  3. Agent operations: load the prompt, check readiness, inspect blockers and review history. Changing inputs marks past reports stale.
  4. Outreach research: run limited free Exa discovery, or load clearly labeled recorded research. Edit and save unsent drafts, retain sources and open a five-second campaign draft.
  5. Economics: change assumptions, compare scenarios and inspect costs, cash proxies and break-even. Invalid scenarios block the export.

Campaigns, storyboards, outreach drafts and review history are browser-local. Use their JSON exports before changing device or preview URL. Campaign and outreach paste imports preserve prior drafts and reset approvals.
